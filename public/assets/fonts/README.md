# Self-Hosted Source Fonts

Downloaded 2026-10-29 from Adobe's official `release` branches. Binaries are unmodified; local filenames are shortened for consistent URLs. License files are retained alongside the fonts.

## Source Sans 3
- Repository: https://github.com/adobe-fonts/source-sans
- Upstream files: `WOFF2/TTF/SourceSans3-Regular.ttf.woff2` and `WOFF2/TTF/SourceSans3-Semibold.ttf.woff2`.
- Local files: `source-sans-3-regular.woff2`, `source-sans-3-semibold.woff2`.
- License: `source-sans-LICENSE.md` (SIL Open Font License).

## Source Serif 4
- Repository: https://github.com/adobe-fonts/source-serif
- Upstream files: `WOFF2/TTF/SourceSerif4-Regular.ttf.woff2` and `WOFF2/TTF/SourceSerif4-Semibold.ttf.woff2`.
- Local files: `source-serif-4-regular.woff2`, `source-serif-4-semibold.woff2`.
- License: `source-serif-LICENSE.md` (SIL Open Font License).

Both families use `font-display: swap`. Chinese text uses explicitly named platform fonts; the Source fonts do not supply Chinese glyphs.
