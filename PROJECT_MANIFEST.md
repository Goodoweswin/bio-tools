# Project Manifest

## Project Overview
- **Name**: Bio-Tools (biotools)
- **Description**: A personal academic website for a Plastic Surgery PhD Candidate, focusing on AI4Med, Single-Cell Omics, and Skin Aging.
- **Goal**: To showcase research, share bioinformatics tools, and build a knowledge base.
- **Owner**: PhD Candidate (Plastic Surgery & AI4Med)

## Core Identity
- **Theme**: "Nature Blue" (#0072B2) with Coral (#FF7F50) accents.
- **Style**: Clean, academic, mobile-first, static HTML/CSS.
- **Language**: English (primary), Chinese (knowledge base).

## Key Directories
- `src/`: **Source Code**. All HTML, CSS, and components live here.
- `public/`: **Static Assets**. Images, PDFs, and files served as-is (e.g., `assets/profile.jpg`).
- `scripts/`: Automation scripts (Python) for content generation and maintenance.
- `dist/`: **Build Output**. The final website generated by Vite (ignored by Git).

## Current Status
- **Phase**: Phase 4 - AI Integration & Full Stack Expansion.
- **Last Update**: 2026-01-04
- **Deployment**: 
    - Full Stack: Cloudflare Pages (Frontend + Functions).
- **Recent Achievements**:
    - **Architecture Upgrade**: Migrated AI Backend to Cloudflare Pages Functions (`/api/chat`) to bypass GFW blocking.
    - **Universal AI Support**: Refactored backend to support **Google Gemini** (via Gateway) and **Any OpenAI-Compatible Provider** (DeepSeek, Doubao, etc.) via environment variables.
    - **AI Gateway**: Integrated Cloudflare AI Gateway for unified logging, caching, and rate limiting across all providers.
    - **Documentation**: Created `AI_CONFIG.md` to guide model switching and configuration.
    - **Identity**: Updated System Prompt to give the AI a clear persona as the "Bio-Tools Research Assistant".
