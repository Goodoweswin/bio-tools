# Project Manifest

## Project Overview
- **Name**: Bio-Tools (biotools)
- **Description**: A personal academic website for a Plastic Surgery PhD Candidate, focusing on AI4Med, Single-Cell Omics, and Skin Aging.
- **Goal**: To showcase research, share bioinformatics tools, and build a knowledge base.
- **Owner**: PhD Candidate (Plastic Surgery & AI4Med)

## Core Identity
- **Theme**: "Nature Blue" (#0072B2) with Coral (#FF7F50) accents.
- **Style**: Clean, academic, mobile-first, static HTML/CSS.
- **Language**: English (primary), Chinese (knowledge base).

## Key Directories
- `src/`: **Source Code**. All HTML, CSS, and components live here.
- `public/`: **Static Assets**. Images, PDFs, and files served as-is (e.g., `assets/profile.jpg`).
- `scripts/`: Automation scripts (Python) for content generation and maintenance.
- `dist/`: **Build Output**. The final website generated by Vite (ignored by Git).
