# Project Manifest

## Project Overview
- **Name**: Bio-Tools (biotools)
- **Description**: A personal academic website and bioinformatics toolkit for Jackson Dai, focusing on AI4Med, Single-Cell Omics, Skin Aging, and Regenerative Medicine.
- **Goal**: To showcase research, share bioinformatics tools, and build a knowledge base.
- **Owner / Pen Name**: Jackson Dai

## Core Identity
- **Theme**: Academic cyber-future with off-black surfaces and a restrained cyan/teal accent.
- **Style**: Clean, academic, research-led, mobile-first, static HTML/CSS.
- **Language**: English (primary), Chinese (knowledge base).
- **Design Direction**: Homepage, Research, Tools, Knowledge, and Publications now use a Future Lab OS language. The next improvement area is content accuracy and richer public records. See `for_agent/DESIGN_STRATEGY.md`.

## Key Directories
- `src/`: **Source Code**. All HTML, CSS, and components live here.
- `public/`: **Static Assets**. Images, PDFs, WebP research figures, and tool runtimes served as-is.
- `scripts/`: Automation scripts (Python) for content generation and maintenance.
- `dist/`: **Build Output**. The final website generated by Vite (ignored by Git).
